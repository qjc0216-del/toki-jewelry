# TOKI Jewelry

Luxury editorial e-commerce storefront for TOKI Jewelry.

Brand direction: baroque pearls, warm ivory, burgundy, espresso and champagne-gold details.

## Stack

- Next.js 15
- React 19
- TypeScript
- Responsive CSS

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
